# Nffs

Site da Nffs: sites, landing pages e páginas de agendamento para negócios locais.

É um site estático (um `index.html` com as imagens em `img/`), sem build.

## Publicar no GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch `main`, pasta `/ (root)`.

## Onde editar

- Textos e seções: `index.html`
- Número do WhatsApp: constante `WHATSAPP` no script no fim do `index.html`
- Prints dos trabalhos: pasta `img/`
